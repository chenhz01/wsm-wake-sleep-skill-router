权限核对能力说明：本能力面向通用权限核对场景，提供输入解析、规则处理与结果交付的完整链路，支持批处理规模配置、失败重试、断点续跑与留痕回溯。

典型请求示例：
- 这个开源项目是不是就一个人在维护
- 这个开源库我想引入，先查查它是不是还活跃、是不是单人项目
- 用 代码托管平台 API 评估仓库近四周提交、贡献者数和发版心跳
- 看看某个开源项目是不是只靠一个人撑着

处理流程：先归一化输入并识别字段，再逐项分类、抽取、过滤异常与冲突，按目标格式组装结果并经一致性复核后输出。

说明：本文为通用能力说明，示例仅描述可处理的请求形态，不含具体实现、私有数据或外部依赖，所有命名均为虚构占位。
